# TO-DO-LIST 📝

A simple and interactive **To-Do List web application** built using **HTML, CSS, and JavaScript**.

This project allows users to add tasks, mark them as completed, and delete them — helping you organize daily work in a clean and minimal UI.

## 🚀 Live Demo
👉 https://shivalikathadiwal.github.io/TO-DO-LIST/

## 🔧 Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive layout for all screen sizes
- Clean user interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
